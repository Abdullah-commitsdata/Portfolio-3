# Portfolio-3

This project focused on building a predictive analytics model to estimate used car sale prices using a large real-world vehicle dataset from a Kaggle forecasting competition. The main objective was to help improve pricing accuracy by analysing vehicle specifications, seller information, market conditions, and customer-related attributes. The dataset included thousands of records with features such as mileage, engine size, fuel economy, horsepower, seller ratings, vehicle age, pricing discounts, and dealership locations. The project began with extensive exploratory data analysis (EDA) to understand trends, missing values, feature distributions, and relationships between variables and car prices. The team also performed data cleaning, handled null values, converted inconsistent formats, and engineered new features to improve model quality and predictive performance.

A complete analytics pipeline was developed using Python, Pandas, NumPy, Scikit-learn, XGBoost, and Power BI concepts. Feature engineering and data modelling played a major role in improving the dataset structure, including the creation of new derived variables from pricing, vehicle age, and sales-related metrics. The project also involved encoding categorical variables, scaling numerical features using StandardScaler, and building relational-style analytical datasets for modelling. Multiple machine learning regression models were tested, including Linear Regression, Ridge Regression, and XGBoost Regression, with hyperparameter tuning and cross-validation used to improve performance and reduce overfitting. Feature importance analysis and regularisation techniques were further applied to identify the most influential variables affecting used car pricing.

After comparing all models using RMSE and cross-validation metrics, XGBoost was selected as the best-performing model due to its higher predictive accuracy and ability to handle complex relationships in the dataset. The final solution successfully predicted used car prices with strong accuracy across unseen test data and was submitted to the Kaggle competition leaderboard. The project demonstrated end-to-end capabilities in predictive analytics, machine learning, feature engineering, statistical analysis, business problem solving, and commercial pricing strategy. It also highlighted the use of data-driven decision-making techniques to support pricing optimisation, inventory valuation, and automotive market forecasting.
